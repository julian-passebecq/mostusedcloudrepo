# Technology icon sources

These SVGs are stored locally so the UI does not depend on an image CDN.

- Python, Pandas and PowerShell: Devicon project marks.
- scikit-learn: compact local rendering based on the scikit-learn/Devicon mark.
- Apache Spark and Databricks: Simple Icons project marks, with their standard brand colors applied locally.
- Power BI and Microsoft Fabric: Microsoft Fabric SVG icon package; these marks identify the respective Microsoft products in the filter UI.
- SQL Server: compact Microsoft SQL Server mark based on the SVG used by data-rentgen-ui / SVGL.
- SQL: neutral database/SQL glyph because SQL itself has no single vendor-owned canonical logo.

Product and project names and marks remain the property of their respective owners. They are used here only to identify the corresponding technology filter.
